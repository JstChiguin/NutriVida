# 🌿 NutriVida

**NutriVida** es una aplicación web desarrollada para la asignatura **Desarrollo Fullstack II (DSY1104)**.

El proyecto corresponde a una clínica nutricional y tiene como objetivo permitir que los usuarios puedan conocer los servicios disponibles, consultar información sobre los nutricionistas y comunicarse con la clínica mediante un formulario de contacto.

## 📌 Versión actual

**v1.0.0 — Primera versión estable**

Esta versión corresponde a la primera etapa funcional del proyecto y establece la estructura base sobre la cual se continuará desarrollando NutriVida.

## ✨ Funcionalidades actuales

- Página principal de NutriVida.
- Catálogo de servicios nutricionales.
- Búsqueda de servicios por texto.
- Filtros por tipo de servicio.
- Listado de nutricionistas.
- Página de contacto.
- Formulario de consulta nutricional.
- Validaciones de formulario mediante JavaScript.
- Validación de datos en tiempo real.
- Mensaje de confirmación después del envío correcto del formulario.
- Encabezado y pie de página reutilizables.

## 🛠️ Tecnologías utilizadas
